## 🛠️ Tech Stack & Directory Layout

- **Database / Auth / Realtime**: Supabase (Postgres, Row Level Security on all 14 tables, Supabase Auth, Realtime WebSocket channel)
- **Backend**: Node.js + Express (ES Modules) in `/server`
- **Frontend**: React + Vite + Tailwind CSS in `/client` (Dark trading terminal `#0B0E14`)
- **AI Engine**: Anthropic Claude API (`claude-3-5-sonnet-20241022`) called exclusively from the backend with deterministic quantitative fallback
- **MetaTrader 5 Integration**: Automated JSON / CSV news schedule export for MT5 Expert Advisor news filtering

## 🚀 Getting Started & Installation

### 1. Prerequisites
- **Node.js** v18.0.0 or higher
- **npm** v9.0.0 or higher
- Optional: **Supabase** account (or runs in deterministic local mock mode)
- Optional: **Anthropic API key** (or runs in deterministic quantitative heuristic mode)

### 2. Backend Setup
```bash
# Navigate to server directory
cd server

# Install dependencies
npm install

# Configure environment variables
cp .env.example .env
# Edit .env with your Supabase URL, Service Role Key, and Anthropic API Key

# Run test suite to verify installation (40/40 tests)
npm test

# Start the server
npm run dev
# Backend starts on http://localhost:5000
```

### 3. Frontend Setup
```bash
# In a new terminal, navigate to client directory
cd client

# Install dependencies
npm install

# Configure environment variables
cp .env.example .env

# Build production bundle
npm run build

# Start the development server
npm run dev
# Terminal dashboard available at http://localhost:5173
```

## 🛡️ MetaTrader 5 Expert Advisor Integration

To protect your automated MT5 trading systems from news spread spikes and slippage:

### Method 1: Local File Drop
1. In the platform dashboard, navigate to **Pre-News Risk & MT5**.
2. Click **Export MT5 CSV** or **Export MT5 JSON**.
3. Place the downloaded file into your MT5 terminal data directory:
   ```
   <MT5 Data Folder>/MQL5/Files/macro_news_filter.csv
   ```
4. Insert the provided MQL5 helper function into your Expert Advisor (`EA.mq5`):

```mql5
//+------------------------------------------------------------------+
//| Macro News Filter Integration for MetaTrader 5 Expert Advisor   |
//+------------------------------------------------------------------+
bool IsNewsLockdownActive(string targetCurrency = "USD")
{
   string filename = "macro_news_filter.csv";
   int fileHandle = FileOpen(filename, FILE_READ | FILE_CSV | FILE_ANSI, ',');
   if(fileHandle == INVALID_HANDLE) return false;

   datetime currentTime = TimeCurrent();
   FileReadString(fileHandle); // Skip header line

   while(!FileIsEnding(fileHandle))
   {
      string id       = FileReadString(fileHandle);
      string name     = FileReadString(fileHandle);
      string curr     = FileReadString(fileHandle);
      string impact   = FileReadString(fileHandle);
      string relStr   = FileReadString(fileHandle);
      string startStr = FileReadString(fileHandle);
      string endStr   = FileReadString(fileHandle);
      double maxSpread= FileReadNumber(fileHandle);

      if(curr == targetCurrency || curr == "ALL")
      {
         datetime tStart = StringToTime(startStr);
         datetime tEnd   = StringToTime(endStr);
         if(currentTime >= tStart && currentTime <= tEnd)
         {
            PrintFormat("[NEWS FILTER] Trading halted for %s. Window: %s to %s", name, startStr, endStr);
            FileClose(fileHandle);
            return true;
         }
      }
   }
   FileClose(fileHandle);
   return false;
}
```

### Method 2: Live WebRequest Polling
In MetaTrader 5 &rarr; `Tools` &rarr; `Options` &rarr; `Expert Advisors`, check **"Allow WebRequest for listed URL"** and add:
```
http://localhost:5000/api/risk/mt5-export?format=csv
```
Your EA can poll this endpoint every 15 minutes to synchronize upcoming no-trade windows dynamically.
